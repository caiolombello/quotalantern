# Origin and history

This initial public snapshot comes from the reviewed Python Linux project
[caiolombello/codexbar-linux](https://github.com/caiolombello/codexbar-linux),
based on c626a05bb38881d1d5fe613dce3819cb809b0d88 and its reviewed working changes.
The old repository and its history were preserved; they were not renamed,
rewritten or deleted. This new repository starts with the sanitized release
snapshot rather than republishing old assets of unresolved origin.

The source includes the reviewed meter fixes and A/Facho identity. The original
feature set and provider adapters are retained. The top-level LICENSE covers
original contributions authorized by the project owner. CodexBar inspiration
and its MIT notice are preserved in NOTICE and LICENSES. No general claim of
sole authorship is made for external dependencies.
